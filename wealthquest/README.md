# WealthQuest 📈

A mobile **life-sim / stock-market game** built in Flutter.

You start at **age 18** with a day job. Each **Next Day** advances one in-game
**week**: your salary lands, living expenses come out, and every market moves.
Put your cash to work across a growing catalog of investments — savings, CDs,
bonds, stocks, ETFs, and crypto — and watch your **net worth** compound (or
crater). Better careers unlock as you age.

> Concept: "A stock-market simulator where at the end of the day you press
> Next Day and see how your assets perform — with CDs, bonds, and every kind of
> investment, across categories. Start small with passive income from a day job
> at 18; every 'day' is a week."

---

## Status — MVP core loop (v0.1)

This is the **first nail**: a complete, playable core loop, built to be
extended rather than rewritten.

**In the build:**

- ⏭️ **Next Day** advances one week — salary in, expenses out, markets move,
  interest/coupons accrue, CDs mature, you age up every 52 days.
- 💹 **Data-driven catalog** (`lib/data/catalog.dart`) of 17 instruments across
  5 categories. Each asset is one `AssetDef` entry.
- 🏦 Six **asset behaviours** (`AssetKind`): liquid savings, locked CDs,
  coupon-paying bonds, and price-walking stocks / ETFs / crypto.
- 📊 **Dashboard** with a net-worth sparkline, cash-flow stats, and an activity
  feed.
- 🛒 **Market** (buy) and 💼 **Portfolio** (sell / redeem, with live P/L).
- 🧑‍💼 **Life** tab: a career ladder that unlocks higher-paying jobs by age.

**Deferred (the obvious next nails):**

- Persistence (save/load), so a run survives app restarts.
- Career as a richer system (applications, promotions, education).
- More categories: real estate, options, commodities, index of indexes.
- Market regimes / news events that shock whole categories at once.
- Goals, achievements, retirement / win condition.
- Margin, dividends-as-reinvestment, tax.

## Running it

This repository ships the **source** (`lib/`, `test/`, `pubspec.yaml`). The
platform folders (`android/`, `ios/`, `web/`, etc.) are generated by Flutter.
From the project root:

```bash
flutter --version          # needs Flutter 3.4+ / Dart 3.4+
flutter create .           # generates android/ios/web around the existing lib/
flutter pub get
flutter run                # on a connected device / emulator
flutter test               # runs the engine unit tests
```

`flutter create .` will not overwrite the existing `lib/` or `pubspec.yaml`; it
only fills in the missing platform scaffolding.

## Architecture

```
lib/
  models/        Plain data: AssetDef, AssetKind, Holding, JobDef
  data/
    catalog.dart Single source of truth — assets, categories, jobs, economy
  engine/
    market_engine.dart  Pure, testable market math (random walk, Box–Muller)
  state/
    game_controller.dart  ChangeNotifier — time, cash, holdings, advanceDay()
  util/format.dart        Money / percent formatting
  ui/            Header + Dashboard / Market / Portfolio / Life tabs + widgets
test/            Unit tests for the core loop
```

Design rules (mirroring the parent repo's discipline):

- **Tunables live in `catalog.dart`.** Returns, volatilities, APYs, job pay,
  starting cash, and living expenses are all named constants there.
- **The engine branches on `AssetKind`, not on specific assets.** A new
  instrument is data, not code.
- **Market math is pure and seedable** (`GameController(seed: ...)`), so the
  simulation is deterministic and unit-testable.

### Adding an investment

Append one entry to `Catalog.assets`:

```dart
AssetDef(
  id: 'reit', name: 'City REIT', ticker: 'REIT',
  categoryId: 'funds', kind: AssetKind.etf,
  basePrice: 88.0, dailyDrift: 0.0013, dailyVol: 0.026,
  blurb: 'Real-estate income fund.',
),
```

It shows up in the Market tab, is buyable/sellable, and moves every Next Day —
no other changes required.
